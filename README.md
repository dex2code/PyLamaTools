# PyLamaTools

Простой чат-оркестратор с возможностью расширения локальных инструментов.

---

## Требования

- **Ollama** – сервер с запущенной моделью (API URL задаётся в `config.py`).
- **Python 3.10+** – для создания виртуального окружения.
- **Git** – для клонирования репозитория.
- Очень рекомендуется модель семейства qwen3.5+ как максимально подходящая для работы с инструментами

---

## Установка и запуск

Выполните последовательно команды в терминале:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/dex2code/PyLamaTools.git

# 2. Перейдите в папку проекта
cd ./PyLamaTools

# 3. Создайте виртуальное окружение
python3 -m venv ./.venv

# 4. Активируйте виртуальное окружение
source ./.venv/bin/activate

# 5. Обновите pip до актуальной версии
pip install --upgrade pip

# 6. Установите зависимости
pip install -r ./requirements.txt

# 7. Запустите приложение
python3 -m main
```

---

## Настройка

1. Отредактируйте файл `config.py`, указав корректный URL вашего сервера **Ollama** (по умолчанию: `http://localhost:11434`).
2. При необходимости измените другие параметры (модель, порт и т.д.).

---

## Примечания

- При первом запуске убедитесь, что сервер **Ollama** запущен и доступен.
- Для остановки приложения нажмите `Ctrl+C`.
- Все зависимости перечислены в `requirements.txt` – их установка обязательна.
